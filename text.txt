								Django
				
Django is a free, open-source, powerful web framework, written in python, used to build secure, fast and scalable websites easily.

Django was developed by 2 web developers Adrian hoovaty and Simon willison in 2003 and in 2005 they made as open source.

They both were working for a news website company(Lawerence Journal World, US), to build the news websites quickly they developed Django.

Library->Tools, Function/codes
Framework - Tools, Function/codes + Complete Structure and rules.

Features of Django:
1. Fast Development
2. Secure-Django Protects our websites automatically against SQL Injection, Cross site Scripting,CSRF
3. Scalable
4. Batteries Included
5. Oprn Source
6. Built-in Admin Panel

							Django Installation

1. Create a Virtual Environment
	
>python -m venv test

2. Activate Environment
>test\scripts\activate

3. Django Installation
>pip install django    --->Current version

or

>pip install "Django==5.2"


To check version:
	>django-admin --version

4. Project Creation
>django-admin startproject firstproject

5. App creation
>cd firstproject
>python manage.py startapp userapp

Request and Response

Types of Request:
1. GET - Retrieving the data
2. POST - Creating a new Data
3. PUT - Updating the data
4. PATCH - Partial Update
5. DELETE - Deleting the data

Types of Response in Django:
1. HttpResponse - It will return a plain text
2. JsonResponse - It will send data in the form of JSON Object
3. render - IT will share HTML page as a response
4. redirect - Used to navigate from one url to another url
